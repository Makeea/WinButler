# info

Scripts that collect and export system information to a `System Information` folder on the desktop.

| Script | Description |
|---|---|
| `get-hostname.ps1` | Saves the machine hostname to a text file |
| `NetworkInformation.ps1` | Saves network adapter configuration |
| `OperatingSystemVersion.ps1` | Saves the Windows OS version |
| `TimeZone.ps1` | Saves the current time zone |
| `Uptime.ps1` | Saves days and hours since last boot |
| `ProductKey.ps1` | Attempts to retrieve the Windows product key via WMI (may not work on all systems) |
| `LastUsedDates.ps1` | Saves last-used dates for installed applications from the registry |
| `list-installed-programs.ps1` | Saves a list of all installed programs with version and publisher |
| `get-wifi-passwords.ps1` | Saves saved Wi-Fi SSIDs and passwords |
| `install-date.ps1` | Displays the Windows installation date |
| `windows-info.ps1` | All-in-one: hostname, uptime, OS version, network, timezone, programs, and Wi-Fi in one run |
