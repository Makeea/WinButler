# setup

Scripts for setting up a fresh Windows machine or installing specific tools.

| Script | Description |
|---|---|
| `post-install.ps1` | Comprehensive post-install setup: system features, browsers, dev tools, security tweaks, and more |
| `nodejs.ps1` | Downloads and silently installs the latest LTS version of Node.js |
| `office365-login.ps1` | Connects to Microsoft 365 using the MSOnline PowerShell module |
| `proxmox-qemu-guest-agent-win.ps1` | Downloads and installs the QEMU Guest Agent for Windows VMs running on Proxmox |

## Requirements

- Administrator privileges
- Internet connection
