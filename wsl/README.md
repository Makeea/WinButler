# wsl

Scripts for installing, managing, and removing Windows Subsystem for Linux.

| Script | Description |
|---|---|
| `wsl-installer.ps1` | Full WSL management: install, choose a distro, and uninstall. Supports multiple distributions |
| `setup-wsl2-ubuntu.ps1` | Installs WSL2 with Ubuntu specifically |
| `Remove-WSL.ps1` | Completely removes WSL and all installed Linux distributions |

## Requirements

- Windows 10 (build 19041+) or Windows 11
- Administrator privileges
- Internet connection (for distro download)
