# debloat

Scripts for removing bloatware, disabling telemetry, and applying privacy and performance tweaks.

| Script | Description |
|---|---|
| `decrapify.ps1` | Win10/11 debloat script — removes built-in apps, disables telemetry, and applies privacy/performance defaults. Based on the Disassembler Windows Initial Setup Script |

## Requirements

- Administrator privileges
- Review the script before running — many settings are applied automatically. Comment out sections you want to skip.
